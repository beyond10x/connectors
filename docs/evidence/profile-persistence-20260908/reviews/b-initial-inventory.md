# Reviewer B — baseline logical persistence/atomicity inventory

This is a read-only inventory and recommended set of singular logical owner labels, not implemented traits, a new universal store, a database selection or source edits. Each family retains its existing semantic authority. Rows identify the port boundary the design inventory must name; several ports may be backed by one host metadata authority where the selected atomicity requires it. Durable and transient responsibilities must remain distinct.

Deferred design obligations must remain visible as unselected rows, without new protocol: product assignment/provisioning owner (design615,691,716–718); durable event-ingress/delivery/checkpoint owner (design726,745–755); execution/job restart/output retention owner (design462); deployment artifact cache/supervision and telemetry retention (design808–814,955). Events/persistent resources/execution lack selected first-profile bindings, and cannot discharge event-claim approval or runtime availability. Catalog specification bundles are build/deployment artifacts, not an execution-authorization store. Media adds bounded transient queues and endpoint accounting, not another durable session owner.

## Actual ESS inventory

The 11 declared entities are AdapterSpecification, OperationDeclaration, ServiceConfiguration; CredentialGeneration; DispatchAdmission; RefreshAttempt; AttemptRecord; KeyReservation; DeliveryReceipt; ApprovalRedemption; Session. Exact identities/relations/lifecycles are preserved in ess-entity-inventory.json. Being an ESS entity is not evidence that an implemented durable backend exists: DispatchAdmission is explicitly transient; CredentialGeneration is immutable captured identity without current-usable lifecycle; Session models one supervisor and no restart reattach.

Not declared: persistent Connection, Acquisition, AuthProfile, CredentialSet/custody version, execution AuditRecord, evidence snapshot entity, observation/collection/mediated-route owner, Composition, event subscription/checkpoint or product assignment/provisioning entities. EvidenceSnapshot is a value; auth_access/connection_admission/discovery/service_wire shapes are values, not persistent owners. idempotency.RouteBinding is a gateway fingerprint value, not the discovery route record. Public descriptive/readiness values must not be reinterpreted as durable authority.
