## Limits retained by the specification

The proposed auth_access domain adds 15 value shapes, not persistent Connection/Acquisition/AuthProfile/cache/route ownership or an executable admission/coordinator implementation. Cross-field profile/flow validity, provider source adequacy and interpretation, numeric ceilings, reservation/consumption, current authority/time, exact private binding/cache equality, coverage completeness, transport pinning, publication/revocation and cursor invalidation remain explicit normative predicates and implementation obligations. Generic Optional omission and Timestamp formats are not the required-null public/configuration codec. No selected payload or profile may advertise support merely because these values compile.

Concrete protected UI/coordinator/custody, no-material transport admission, exact auth-query capability, supporting strict readers, discovery-generation accounting and read-retry behavior retain their named owners and advertisement gates. Those explicit exclusions do not contradict the bounded semantic selections approved here. No source/planning files were mutated and no runtime test suite was executed by this reviewer.
