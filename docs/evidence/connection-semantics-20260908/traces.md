# Connection semantics textual traces

These cases declare trusted facts and expected observations; they do not execute a provider, coordinator, clock, custody binding or callback. The separate decision vectors cover all seven global states, priority overlaps and exact-operation eligibility.

| ID | Facts | Required consequence |
|---|---|---|
| C01 | Profile minimum read grant present; requested optional write grant absent. | Candidate may publish after other baseline checks; completed records definite publication. Read remains eligible, write is insufficient_scope. Enablement of another write does not change global state. |
| C02 | Initial candidate fails profile minimum or mandatory global verification. | No active publication/completed; canonical insufficient_scope for known missing minimum. Stored private candidate/orphan is not a completed connection. |
| C03 | Refresh narrows optional grants but establishes the minimum and required baseline checks. | New generation may publish; old admissions are cut off. New read admission can succeed; removed write grant refuses. |
| C04 | Rotating source consumed, candidate grants unknown/below minimum or mandatory verification fails. | No candidate publication and no restoration of old source authority; refresh's conservative repair/uncertainty rules remain. |
| C05 | Independent inactive repair candidate has wrong identity while old generation is valid. | Reject candidate as identity_mismatch; old binding/state survives unless independently expired, revoked or consumed. Detected replacement of current material instead blocks its dispatch pending validation. |
| C06 | Only an optional operation-specific verification is stale/not_run/failed. | Global viability is unaffected; only operations requiring that check refuse. A supported hook is not automatically a universal requirement or permission to probe. |
| C07 | Metadata unavailable, or stale baseline evidence. | Metadata outage returns unavailable without an invented state. Readable metadata with stale mandatory baseline validation yields pending; neither means proven invalid credential. Describe performs no provider probe or credential capture. |
| M01 | Admitted creator has no existing connection. | Create targets the instance/profile and omits Invocation.connection; host coordinator owns one acquisition. No implicit configured connection is fabricated. Interactive actions go to the trusted UI channel; noninteractive client credentials may complete without UI. |
| M02 | Caller has business access but lacks receiver management grant. | Refuse management with not_granted before private state disclosure. Opaque refs/provider grants do not help. Adapter/connection/resource restriction failures use forbidden. |
| M03 | Existing connection pending/disabled/degraded; caller can inspect/repair/revoke. | Metadata/status and admitted coordinator actions remain possible without business readiness. Provider work has its own prerequisites. Revoked is inspectable/revocable but cannot be repaired or re-enabled. |
| M04 | Outer management selector conflicts with body repair target, or explicit null is supplied. | invalid_input. Connection-scoped describe/revoke/repair requires one exact nonempty string; create/list/status omit the member and reject any supplied selector. F03 nullable signed claims do not change that wire rule. |
| M05 | Begin owned by leaf A; gateway alias is repointed to B before status/completion. | Route to the retained owner A only if currently admitted and reachable, otherwise refuse; do not recreate/rebind state at B, resend exchange or substitute gateway authority. |
| M06 | Management authority withdrawn after begin, or repair target revoked/revised. | Recheck stored originating scope/target before exchange and publication; refuse stale completion/publication. A one-use callback capability cannot restore authority. |
| M07 | Local revocation commits, then custody/provider revocation fails or response is lost. | Local state stays revoked and old admissions remain fenced. Provider cleanup remains failed/unavailable/unknown as observed; never claim success, restore local access or automatically repeat a possibly consumed call. |
| M08 | Ordinary discovery/list/status/begin/model audit inspected for control data. | No credential, custody ref, registration secret, code/state or actionable completion URL. Interactive ordinary begin returns safe ref/expiry/action kind; only the separately admitted confidential trusted UI channel receives the one-use continuation/entry schema. |
| M09 | Protected completion successfully publishes a candidate. | Custody and baseline publication acknowledgements precede completed. Caller receives a safe connection ref and explicitly invokes any later business operation; completion itself never retries prior work. |

Core evidence defaults remain 300 s for cached read evidence and 60 s for mutations; each check's shorter validity and final generation/publication/revocation fence still win. Acquisition expiry remains the selected 600 s browser / 300 s protected-entry defaults. This checkpoint does not select permission fan-out budgets, automatic read refresh retry, concrete management mutation/approval payloads or backend atomicity; those retain their existing owners and advertisement gates.
