# The web explorer works against the site JSON M1 actually emits

## Resolution

The migrated VitePress explorer never matched the M1 projection and was never shipped or gated.
Repairing a second product UI would duplicate the authenticated catalog experience now owned by
DevCenter. This story is therefore closed by retirement rather than restoration.

## Acceptance

- [x] The dormant `web/` application, its Node manifests, tests, schemas, and brand copies are
      removed together.
- [x] `catalog-build` no longer constructs or writes `web/public/catalog.json`; the site-only model,
      renderer, status projection, and surface helpers are removed from the build graph.
- [x] JSON governance, source ownership, ignore rules, architecture fences, and local gate guidance
      no longer name the removed projection.
- [x] Catalog browsing is served from the hosted, authenticated Catalog protocol and presented by
      DevCenter, while canonical documents and `catalog.pack` remain the reviewed build artifacts.

## Progress

- 2026-09-02: retired the unshipped explorer and moved product browsing ownership to DevCenter.

## Notes

- Historical references in completed migration stories remain provenance, not active ownership.
- Connector API reference documentation remains generated by the hosted server and can be exposed
  by a product deployment independently from the catalog browser.
