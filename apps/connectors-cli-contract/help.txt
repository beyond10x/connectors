Local integration access through explicitly configured connector instances. After an upgrade, `connectors setup owner-stop` stops the owner an older binary started

Usage: connectors [OPTIONS] <COMMAND>

Commands:
  adapters     
  approvals    
  connections  
  definitions  
  instances    
  list         List every connector this build ships, with its auth profiles and the instances the configuration names; needs no configuration and starts no process
  operations   
  setup        
  completions  Emit shell completions
  help         Print this message or the help of the given subcommand(s)

Options:
      --config <global_config>
          

      --state-dir <global_state>
          

      --output <global_output>
          [default: human]
          [possible values: human, json]

  -h, --help
          Print help
