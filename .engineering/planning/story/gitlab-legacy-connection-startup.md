## Outcome

Start a hosted Connector with pre-grant-binding GitLab connection metadata without authorizing that metadata or taking unrelated integrations offline. Existing unbound connection rows remain durable but cannot appear as usable connections, lease credentials, fetch sources, or perform provider requests. A normal current-authority connect flow verifies fresh credentials and replaces the row with an explicit current grant binding. Unbound pending transactions remain uncommitted and cannot regain authority during startup recovery.

## Acceptance

Regression tests exercise legacy rows decoded without a grant field, preserved state, no credential or provider access, pending transaction isolation, refusal of malformed state, and recovery after a verified current-authority reconnect. Preserve the Git v2 behavior and full repository gate. Publish the compatible provider and its exactly aligned generated-service consumers before retrying the deployment.

## Implementation evidence

The backend now keeps unbound metadata durable while admitting no connection or credential access through it. Recovery skips pending transactions whose grant is absent or differs from current configured authority. An empty grant policy is refused. A regression scenario decodes an actual legacy row without a grant field, verifies no provider call or state rewrite, completes normal verified PAT reconnection while preserving the connection identity, and confirms the legacy pending transaction remains untouched. Malformed state remains refused.

All 40 GitLab integration tests passed, including Git v2 interoperability, and affected all-target Clippy passed with warnings denied. Connectors 0.6.5 catalogs were regenerated by catalog-cli and all nested locks were refreshed. The complete repository gate is running; this source candidate is not yet approved as green for main or runtime release.

## Completed validation

The complete repository gate passed for this source candidate. The affected GitLab transport and upgrade regression suite also passed all 40 tests, and all-target Clippy passed with warnings denied. Exact provider source pins retain current-authority checks and the existing service contracts. This source is ready for the approved provider-first rollout; hosted success remains dependent on verifying the published runtime artifacts and normal reconnection of legacy GitLab accounts.
