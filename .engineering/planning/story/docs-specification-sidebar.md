## Outcome

The site's navigation shows a user the pages a user opens; the contract and model pages sit in one
collapsed "Specification" category, with no URL change.

## Why now

Post-0.54.0 docs review (run 3, 2026-10-19, lane D5, verified): of 1,779,438 B under `website/docs`,
1,522,981 B (85.6 %) is generated, and 107 pages (1,456,939 B) are contract and model specification
(`reference/contracts/**`, `reference/adapters/*/contracts|model/**`) that a CLI user does not open.
They share the autogenerated Reference category with the CLI reference (`website/sidebars.ts:39`).
`reference/adapters/catalog/index.md:24` says Zendesk is verified against "a live account"; the
connector page and `docs/catalog-zendesk.md:296-299` say fixtures only. Several adapter index pages
repeat their connector page (catalog 38-54, gitlab 10-12 and 110-123, sql 43-57, tavily 24-32,
prometheus three limit bullets).

## Acceptance

- `website/sidebars.ts` has a collapsed "Specification" category holding `reference/contracts/**`, each
  `reference/adapters/<x>/contracts` and `/model` directory, `reference/crates.md`,
  `concepts/contracts.md` and a "Maintainers" entry for `guides/build-a-catalog-bundle.md`; Reference
  keeps `reference/cli`, `reference/adapters/index` and the hand-written adapter pages. No page moves.
- `website/tests/overhaul.mjs` and `smoke.mjs` pass.
- `reference/adapters/catalog/index.md:24` reads "local fixtures; no live account yet"; the repeated
  adapter-index blocks above become links to the connector pages.
- Files: `website/sidebars.ts`, `website/docusaurus.config.ts` if needed, hand-written
  `website/docs/reference/adapters/**/index.md`.
