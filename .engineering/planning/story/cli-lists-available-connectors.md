## Request

Operator, 2026-10-22, verbatim: "add taskfile for that purpose, also add some sub cli command to
connector which will print all available connectors". "That purpose" is installing the CLI from a
checkout: `task install` failed with `No Taskfile found`.

## Outcome

- `connectors list` prints every connector this build can serve, one row each: the connector id,
  its auth profiles, and the names of its configured instances (none when not configured). It needs
  no configuration file and starts no process.
- `--output json` prints the same rows as JSON.
- The list holds the connectors the catalog provider ships a declaration for
  (`adapters/catalog/providers/*/connector.json`) and the connectors served by their own
  executables; no row names an implementation (`catalog`).
- `Taskfile.yml` at the repository root has `task install`, which installs `connectors` and
  `connectors-catalog-provider` from the checkout with `cargo install --locked`.

## Acceptance

- `connectors list` with no configuration exits 0 and has a row for `gitlab`, `gmail` and
  `zendesk`.
- With an instance `gitlab/work` configured, the `gitlab` row names `work`.
- No row of `connectors list` or `connectors list --output json` contains `catalog`.
- The CLI reference regenerated by `connectors-docs generate` documents `connectors list`.
