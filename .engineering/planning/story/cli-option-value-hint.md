## Gap

Found by the adversary of story:credential-from-environment-variable (2026-11-12). Bash completion
of `--credential-env` offers file names: the completion script is generated by `clap_complete`
over the generated CLI, which falls back to `compgen -f` for a value option without a value hint
(`--endpoint`, `--profile` and `--config` behave the same). The ESS `option` binding source has
only `long`; a `hint` key is rejected, so the generated CLI cannot set `ValueHint::Other`.

## Acceptance

- The CLI specification can give an option a value hint (none, file, directory), and the generated
  completion for `--credential-env`, `--endpoint` and `--profile` offers no file names; a test
  reads the generated `completions/connectors.bash` for those options.
