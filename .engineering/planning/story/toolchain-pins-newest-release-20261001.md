## Defect

The gate accepts only ESS 0.45.0 (`crates/connectors-spec/toolchain.json`) and AEP 0.65.0
(`crates/connectors-build/aep-toolchain.json`). ESS 0.48.0 and AEP 0.67.0 are released
(`gh release list` on 2026-09-30), and `b10x upgrade` installs the newest, so on a machine set up the
documented way the gate refuses with "requires ess 0.45.0; no matching ESS executable" and
"AEP 0.65.0 is required". On 2026-09-30 the gate ran only after 0.45.0 was found in
`~/.cache/ess/toolchains/` and 0.65.0 was downloaded by hand.

## Change

Move both pins and the seven ESS Cargo dependencies (`ess-*`, tag `0.45.0` in
`Cargo.toml:25-31`) to the newest releases, regenerate owned outputs, as
`story:ess-pin-newest-release` did for 0.45.0.

## Scope

- `crates/connectors-spec/toolchain.json`, `crates/connectors-build/aep-toolchain.json` — cited.
- `Cargo.toml`, `Cargo.lock` — cited: `Cargo.toml:25-31`.
- `docs/development.md` — cited: "Pinned tools".
- generated outputs under `apps/connectors-cli-contract/` and `ess/` — inferred.

## Acceptance

- `connectors-build gate --msrv` passes with the newest ESS and AEP as installed by `b10x upgrade`.
- Generated outputs are regenerated by their owning commands; none is edited by hand.
- `docs/development.md` names the new versions.
