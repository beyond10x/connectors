## Bounded unit

One baseline, one candidate, one decision. Keep the existing acceptance unchanged:
release builds, identical complete baseline fixture set at requested 50/600/1200
events with actual counts recorded, warmup then five measured invokes, both owning
cost probes, and every required clock/revision/corruption invariant. All failures
remain visible. Adopt only when every invariant and success requirement holds and
the 1200-event median is at most twice the 50-event median. Otherwise reject and
remove the candidate from production source. Retain Entity Runtime issue 51 as the
upstream fix; it was rechecked OPEN with no comments after v0.25.0 publication.
A successful mitigation would still not close 600/6000-event and 700-invoke M1 acceptance.

Read-only scoping identified one minimal candidate at persist_batch in
crates/connectors-host/src/local/metadata/er.rs: retain synthetic equal-value clock
CAS for PreparedObservation but suppress it for Standard business persistence
when the clock itself did not change. This is a falsifiable experiment, not a claim
that the candidate is safe. The existing same-millisecond observation fence is
expected to reject it; record actual output. Do not change changed-clock actions,
RuntimeStateOnly boundaries, postcommit checks, catch-up/blob verification, the
30-second bridge wait, or split writes into a new protocol. No second candidate.

The two cost probes use the same complete saved baseline fixtures, never stores
generated by the candidate. Preserve full output and fixture hashes. A command
exit 0 that printed probe failures is not acceptance. Reassess at one working day;
if a required measurement cannot finish, record it as incomplete rather than
invent a median or quietly change the acceptance. No new product entity.

## Scope, builds and ownership

Worker owns only its isolated experiment tree and source candidate at metadata/er.rs;
existing registry tests/cost probes supply measurements. Any necessary additional
Rust-only probe code or fixture seam must return for explicit scope review. Root
owns AEP, publication reports and the decision record. Candidate source is retained
as a patch/evidence and reverted on rejection. No unsafe source is integrated just
to make an experiment commit. Independent review checks the retained comparison,
invariants, decision and exact final source state; it does not introduce another
candidate or relabel unrun checks as passed.

One worker/build lane with two Cargo jobs, no shared mutable target. Maintain 8 GiB
free and inspect storage before release compilation. The warm integration target
was transferred exclusively to cb26c-plan after all v0.25.0 checks completed;
it is not shared with this worker. If disk reserve cannot hold, pause new build
work and preserve outputs rather than deleting unrelated caches.
