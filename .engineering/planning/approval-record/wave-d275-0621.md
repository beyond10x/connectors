## Decided in the wave

- The `0640` group-read rule applies to the review token only; every other credential file keeps
  `0600`.
- The documented review token path becomes `.../serviceaccount/..data/token`; the code keeps
  refusing a final symbolic link and following intermediate ones.
- A world-writable state directory or ancestor stays refused; the refusal names the directory and
  the reason, and the docs give the volume layouts that start.
- Read scope is a new `catalog.repositories` key. With it set, an operation is admitted only when
  its `owner` and `repo` inputs name a listed repository (else `not_found`, nothing sent upstream);
  operations without both inputs are refused and hidden, because a filtered page would end a walk
  early.
