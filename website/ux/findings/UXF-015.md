# UXF-015: The CLI reference's global options have an empty Meaning column

The first table of the CLI reference, "Global options", has a Meaning column and leaves it empty
for all three options. The value placeholders are field names (`<global_state>`), not words a
reader would say. A reader who needs `--state-dir` (the upgrade guide sends them there) must look
it up elsewhere.

One line: the clap definition gets help text for the three global options, and the generator fails
on an empty Meaning cell.
