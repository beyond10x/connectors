# UXF-001: The site has no search

The adapter names search as an always-visible element. The navbar of every page has none: Docs
System, pinned in `website/package.json`, offers no search, and the design record removed the site's
own Pagefind search until the shell has one. A reader who knows the word (`--walk`, `pod exec`)
must browse: the screen-only user needs 6–16 actions on the rotating card where one search would do.

Fix belongs in Docs System (a search the shell ships to every site). The gate holds it as a known
loss (`knownAbsent` in `ux/adapter.ts`); gate 2 fails with "present now: close UXF-001" once the
shell ships search, so the record cannot stay open past the fix. Site-local search instead is the
question of `rounds/R-01/decision.md`.
