# UXF-014: The CLI reference names no exit status and does not link to the contract

A reader with a question about `connectors invoke --walk` opens "connectors CLI" under Reference:
it lists every option but no exit status and no link to the "Local CLI" contract under
Specification, where the answer is. The reader has to know that a second page about the same CLI
exists. Without search (UXF-001) there is no one-action way across.

One line: the generator adds, per command section, a link to its section of the Local CLI contract
(and one line in the intro naming the contract as the source of exit statuses).
