# UXF-005: The status page is a long scroll

`/docs/status` lists every surface in tables under five sections. A reader looking for one row
(Kubernetes pod exec) has no link that lands on it and scrolls 12 to 22 screens. The page is
generated by `connectors-docs`, so the fix is in the generator (a row anchor or a jump list), not
in the site's CSS. Site search would also close it (UXF-001, decision.md).
