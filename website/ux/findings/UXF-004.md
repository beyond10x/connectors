# UXF-004: Wide tables on contract pages scroll in a box the keyboard cannot reach

The site's `src/css/tables.css` predates Docs System's table wrapper. It makes every Markdown table a
scrolling block, which beats the wrapper's own rule. On `/docs/reference/contracts/cli` two tables are
wider than the column at 1366x768: each scrolls inside the table element, which has no tabindex, so a
keyboard user cannot scroll it, and the wrapper's guidance ("focus the table and use the arrow keys")
stays hidden because the wrapper itself never overflows.

Fix (site, cost S): limit the site rule to a table outside the wrapper, so the wrapper scrolls, takes
focus and names the region.
