# UXF-003: At the end of a docs page the sidebar slides up under the navbar

The docs sidebar is sticky inside its column, and the column ends where the footer starts. When the
reader reaches the end of a page, the footer pushes the sidebar up: at 1366x768 on `/docs` its top
297 px sit above the viewport, under the fixed navbar, so the first sections of the navigation are
gone until the reader scrolls back up. It happens on every docs page in both themes.

Fix belongs in the docs layout of Docs System (the shell owns navigation and layout,
`website/README.md` § Edit the owning source): for example the footer inside the content column so
the sidebar column reaches the bottom of the page, or a sidebar that shrinks rather than moves. The
gate holds `sidebar@end` as a known loss (`knownHidden` in `ux/adapter.ts`); the test named above
fails once the layout is fixed.
