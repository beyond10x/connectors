# UXF-017: Contract pages state their status in free text

The Status page defines four states in words (shipped, unreleased, decided, planned). The contract
index and each contract page's callout use a second, free-text vocabulary: about ten different
phrasings, none of them the Status page's words. A reader asking "does this run today?" gets two
answers in two languages and must reconcile them.

One line: lead each contract status with one of the four Status words, the free text after it.
