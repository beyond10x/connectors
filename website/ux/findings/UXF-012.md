# UXF-012: Key data is set below 14 px

The values a reader comes for are smaller than the 16 px body text: the install command on
`/docs/getting-started` is 13.1 px, command names and option names in the CLI and contract tables
are 12.7 px, and the table of contents, the only in-page navigation of the long reference pages,
is 12.8 px with its code entries near 11 px, broken mid-name (`key-` / `init`). axe's
colour-contrast rule passes in both themes, so this is size, not contrast.

One line: raise `pre`, table code and `.table-of-contents` to at least 0.875rem in Docs System.
