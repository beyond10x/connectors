# UXF-002: Links in running text are told apart by colour alone

axe-core reports `link-in-text-block` (serious, WCAG 1.4.1) for links inside paragraphs and list
items on every prose page, in both colour modes: the link differs from the text around it by colour
only, with less than 3:1 contrast between the two, and no underline. A reader who does not see the
colour difference cannot find the links in the text.

Fix belongs in Docs System: the link style of `.markdown` is the shared theme's and every beyond10x
site has the same defect; an override in this site would hide it from the others. The gate holds the
rule as a known loss (`knownAxe` in `ux/adapter.ts`); the test named above fails once the shell's fix
lands, so the exception is dropped then.
