# UXF-011: The landing page's primary button sits on the fold

At 1366x768 the hero's three actions start at about y = 745: only the top 23 px of "Get started"
show and none of the three labels can be read. At 1280x720 they are below the fold. The landing
page's one next action is therefore not on the first screen; the reader falls back to the five
equal navbar links.

One line: less top padding in Docs System's hero (or the lede shortened) so the action row ends
inside 720 px.
