# Docker

Container operations with bounded logs and explicit effects.

Native profiles describe multiplexed log handling and mutation behavior. Docker transport and provider semantics belong to this adapter.

Socket-peer and TLS configuration need their selected bindings. Native contract and ESS sources exist; a Docker adapter runtime is not implemented here.
