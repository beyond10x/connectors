# Prometheus

PromQL series semantics through a shared datasource boundary.

The native profile describes instant and range queries, time and step bounds, series identity and partial results. It keeps PromQL semantics with the provider.

A native contract and adapter design exist. Additional typed model and runtime work remain; this page does not advertise a running Prometheus integration.
