# Grafana

Discover datasource candidates and describe mediated access.

The native model records datasource discovery and route behavior. A discovered datasource is information, not authority to use its underlying provider.

A composition can pair Grafana with a separately implemented child adapter through shared capabilities. Child adapters do not import Grafana implementation details. No Grafana runtime is implemented here.
