# RTVBP

A session and media transport with proof-bound authority.

The native session binding describes protocol authority and shared session/media behavior. It remains distinct from SIP implementation and provider credentials.

Codec, cryptographic and transport enforcement require their own implementation and conformance. This repository does not contain a runnable RTVBP adapter.
