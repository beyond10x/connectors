# Follow a request to GitLab

Your application needs the first 20 issues from **acme/website**. It calls a remote Connectors host, which reaches GitLab through an adapter. What travels between them, and who checks access?

Follow the request and its answer. Start with **configured access**, then explore how the specified architecture adds **user authorization**. These are illustrated journeys with fictional data; no real service is contacted.
