# Understand the guarantees

A contract describes the shared meaning of an interaction: its types, access requirements, lifecycle, limits and failure behavior. An adapter binds those guarantees to a provider.

Start with the [implemented service contract](/contracts/service) for describe and invoke, bounded data reads and endpoint discovery. Follow the [governed service](/contracts/governed-service) for the proposed admission and audit boundary. [Current status](/introduction/status) separates specification coverage from runtime support.

## Follow an interaction

**Discover → select access → invoke → interpret the result.** Discovery reports observations. A connection binds a selected target and access. Admission decides whether this particular request may proceed. The operation and its data profile define the result, including incomplete or uncertain outcomes.

Contract-family versions, service wire bindings and adapter specification versions are independent. [Compatibility](/contracts/compatibility) explains the selected boundaries.
