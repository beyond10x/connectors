# Advanced contract exercises

These exercises examine individual rules: discovery versus access, connection readiness and uncertain mutation outcomes. For the practical picture first, [follow a request from your laptop to GitLab](/introduction/examples).

The exercises run bounded Rust/WASM behavior with fictional in-memory bindings. They do not contact a provider or establish production runtime conformance.
