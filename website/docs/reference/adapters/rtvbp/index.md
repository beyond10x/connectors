# RTVBP

A session and media transport with proof-bound authority.

The native session binding describes protocol authority and shared session and media behaviour.
It remains distinct from the SIP implementation and from provider credentials. Codec,
cryptographic and transport enforcement need their own implementation and conformance. No RTVBP
runtime is implemented.
