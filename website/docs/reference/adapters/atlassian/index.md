# Atlassian

A typed model of the native document vocabulary for Jira and Confluence.

This directory has an ESS model and no runnable Atlassian adapter. Jira Cloud and Confluence Cloud
reads run today through the [catalog provider](../catalog/index.md) from their pinned REST
documents.
